From plan to MP4
Take it from browser to renderer.
The exported JSON is the handoff. Rendering stays local so FFmpeg, model files, intermediate assets, and OAuth credentials use your existing environment.


STEP 01
Export the storyboard
Download storyboard.json. Put it beside a folder called images with scene files named scene_01.png, scene_02.png, and so on. At least five illustrated images are required.
STEP 02
Run ReelGen locally
Open a terminal in your ReelGen project. Install the dependencies and FFmpeg, and configure your chosen voice provider in .env.
STEP 03
Render your video
Use the command below, replacing the source URL and file paths. The renderer assembles narration, scene images, captions, and the MP4.

python run.py render-external --article-url "https://example.com/article" --script "storyboard.json" --images-dir "images" --aspect-ratio 9:16

Read setup guide ↗


This command is a template. Replace the URL and paths with your own values. External rendering requires a valid HTTP(S) source URL for attribution, even when the storyboard was written from scratch.
